# WT YOOtheme Yandex Map
The plugin adds a Yandex Maps element for the YOOtheme page builder in Joomla.

Flexible settings for displaying markers, popups and their contents, clusterization of markers.

## Warning 
<b>Minimum version of Joomla - 4.2, PHP - 8.0</b>

<b>Version 1.2.0 of the extension has been tested on Joomla 6.0-beta3</b>

### Main features
Create an unlimited number of balloon labels on Yandex Map for a Joomla site.
Adding pop-up windows to markers, clustering markers

### Map settings
* map type selection: <b>scheme</b>, <b>satellite</b>
* map color scheme: <b>light</b>, <b>dark</b>
* centering modes:
  * <b>coordinates</b> - specify the map center manually (latitude/longitude)
  * <b>on last marker</b> - the map moves to the last added marker
  * <b>fit all markers</b> - the map displays all added markers
* configurable padding for the map (in % of the height of the map element)
* default zoom value
* maximum and minimum zoom value
* configurable width and height of the element
* adjustment mode available to the size of the device display area
* configurable location of map controls:
  * <b>Zoom and drag the map *</b>
  * Fullscreen control
  * Ruler and planimeter control
  * Rotation and tilt control
  * Search control

### * Note: Starting from version 1.2.0, dragging the map on mobile devices is only possible using two fingers

* clusterization of markers
* configuring the styling and display of a marker cluster element
* configuring the styling of marker content
* configuring the display of a popup window

### Marker settings
* show/hide marker,
* title (marker name),
* short text description,
* custom marker icon (balloon),
* marker color

### Popup settings
* show/hide popup,
* HTML content (editor),
* link,
* image,
* display of the popup window when loading the page,
* position of the popup window relative to the marker (top, right or left),
* custom padding for the popup element

### Installation and configuration
Installation is performed in the Joomla admin panel - in the System - Extensions - Install section.

Setting up and using it is within the framework of the YOOtheme constructor.
